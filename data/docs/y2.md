## SUN 68000 Memory Expansion Board


The SUN 68000 Memory Expansion board provides up to 1 MByte
of additional "on-board" memory for the SUN 68000 board.
The expansion memory, as the main memory of the SUN 68000 board,
is euipped with byte parity and is accesible by the 10 MHz 68000
without wait states.

The expansion memory connects to the SUN 68000 via the P2 connector
of the Multibus.
To install the SUN 68000 Memory Expansion, a P2 Bus connector
must be present to connect the SUN 68000 Board to the expansion
memory boards.

Up to two SUN 68000 memory expansion boards can be added to a
SUN 68000 board. The first memory expansion board can be loaded
with 768 KBytes memory to bring total memory to 1 MByte,
the second memory expansion board can be loaded with an full MByte
of memory to increase total memory to 2 MByte.
