# Desk-top, High-Performance Workstation Joins Family


Andreas Bechtolsheim, Sun Microsystems, Inc.


>


The latest member of the Sun-2 family of workstation
is a desk-top model, the Sun-2/50 disk-less node.
Its visible components are a 19" high-resolution display,
a low-profile keyboard, and a mouse pointing device.

The Sun-2/50 is based on the Motorola 68010 32-bit processor.
It features up to 8 Megabytes of main memory,
an integral Ethernet interface that moves data directly into main memory,
and a high-resolution 1152*900 pixel display subsystem.
All electronics is contained in the footprint of the 19" monitor.

The workstation comes with an enhanced version
of the Berkeley 4.2 UNIX operating system,
featuring disk-less operation, a distributed filesystem,
a multiwindow system, support for CORE and GKS graphics,
and standard languages (C, F77, and Pascal).

The Sun-2/50 diskless node works in conjunction with a
Sun-2/120 or Sun-2/170 fileserver.

#### First Single-Board Workstation


The Sun-2/50 is believed to be the first engineering workstation
that fits all electronics on a single board.
This, a result of much simpler design than previous workstations,
greatly increases reliability and reduces cost.

In the design of the bus-organized models of the Sun-2 family,
the Model 120 and 170, the goals were high-performance and expandibility.
For the single-board machine, the Model 50, the design challenge
was to maintain the same level of performance while squeezing the
workstation design on a single printed circuit board measuring 14.44" by 15.75".

This was achieved by extensive use of LSI and VLSI components
and programmable logic such as PROMs and PALs.
More than half of the chips on the board are LSI or VLSI circuits,
with MSI components (medium scale integration) accounting for one third
and SSI (small scale integration) for the rest.

#### System Architecture


The Sun-2/50 is a member of the Sun-2 family of workstations.
As such, it conforms to the Sun-2 architectural specification
and executes exactly the same software as current and
future Sun-2 workstations.

The Sun-2 architecture specifies all devices that are
supported by the system. While a device, once specified,
cannot be changed and thus will work in the same way,
new devices can be added to the system over time.

One such new device present in the Sun-2/50
that was not available for the previous Sun workstations
is an integral Ethernet interface that transfers data
directly into main memory, using virtual memory addresses.
This interface is based on a VLSI controller that offers
extensive data buffering and diagnostic capabilities.


#### Open versus Closed Systems


The Sun-2/50 offers no user access to its internal bus.
The only options it accomodates is memory expansion
and a floating point processor option.
It is thus a closed system compared to the Sun-2/120 and /170
which offer Multibus based backplanes.

The advantage of a closed system is that it is cheaper
since no space or power have to be provided for expansion.

#### Ergonomic Engineering


In the design of the Sun-2/50, careful attention was paid
to ergonomic engineering issues.

The display of the unit is mounted on a gravity-stabilized
true tilt-and-swivel mechanism, that easily adjusts
to any desired viewing angle.
The display monitor itself is refreshed non-interlaced
at 67 Hz, rather than the usual 60 Hz.
Our testing indicates that 67 Hz flicker is visible
only to a few individuals, whereas 60 Hz flicker is
visible to most members of the population.

The low-profile keyboard features threshold-type keys
with acoustical feedback. The optical mouse requires
no adjustments of cleaning.

#### Sidebar: A New Board Size with a Standard Bus


After anaylsing design requirements for future high-performance workstations,
it became appearent that the current industry standard board formats
provide nowhere near the necessary board space for the designs.
This is illustrated in the table below.

--------------------------------------------------------------------------------
Format		Dimension	Usable Area 	16-pin ICs	16-pin ICs
		[inch]		[sq.inch]	[0.5"/IC]	[0.4"/IC]
--------------------------------------------------------------------------------
Multibus I	6 x 12		70		140		175
Multibus II	9.1 x 8.6	72		144		180
VME 		6.3 x 8.6	50		100		125
Sun 		14.44x15.75	215		430		537
--------------------------------------------------------------------------------

The Sun Board is three times larger than any of the other boards
and it can accomodate more than 500 IC packages.
This is a common number of ICs for such items as color frame buffers
and graphics processors.
It is very difficult to partition such designs into several small boards
because of their high interconnectivity and because of their high speeds.
In fact, since the bus interface circuitry can take up as much as 20%
of the available space on a small board, the area remaining
for the actual subsystem function is even less.

On a sideline, it is interesting to note that all boards
except for Multibus I are based on the Eurocard standard and DIN connectors.

#### No-Wait State performance


The performance goal for the Sun-2/50 was no-wait state execution.
This means that the CPU performs at its fully rated speed,
without being slowed down by a memory system of insufficient performance.
Since every wait state reduces system performance by about 25%,
this was a key issue.

No-wait state operation was achieved by very tight coupling
between CPU, memory management, and main memory.
With high-speed static RAMs for the address translation buffers,
an arbitration-free, synchronous bus to main memory,
and novel RAM chip driving circuitry,
the speed of the MMU and the memory can be made to match
the speed required by the CPU for maximum performance.
