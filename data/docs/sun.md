# SUN Workstation (TM) Features


---


**Optimized for Processor Performance**


	based on 68000 32-bit architecture
	no wait states at 10 MHz produces peak rate of 2.5 MIPS
	benchmarked between VAX11/750 and VAX11/780
	(no Floating Point)


**Optimized for UNIX***


	multiprocess page/segment memory management
	fast context switching among 16 processes
	hardware for virtual memory/demand paging


**Optimized for Raster Graphics**


	Full page 17" landscape display
	1024 by 800 pixel resolution
	Hardware Pixel Processor for BitBlt operations
	Fast Raster Manipulation (32 Million pixels/sec)
	Fast Vector Drawing (up to 1 Million pixels/sec)


**Optimized for Networking**


	Supports 10 Mbit/sec and 3 Mbit/sec Ethernet
	Ethernet provides highspeed communication
	Cluster concept: workstations share disks and
	other pheripherals via network.


**Optimized for Expandability**


	Internal Bus is compatible with IEEE 796/Intel Multibus*
	Peripheral options include color graphics,
	SMD Disk controller, 1/2" Tape Controller, etc.


**Optimized for Low Cost**


	using state of the art VLSI technology
	leads to low chip count, high reliability.

#### Specifications


**Processor**


    10 MHz 68000

**Memory**


    256k Bytes of high-speed RAM with byte parity (no wait states),
    expandable to 1 or 2 Megabytes with SUN memory expansion board.


**Input/Output**


    detachable ASCII keyboard
    10 MBit/sec or 3 MBit/sec Xerox Ethernet interface
    two high-speed RS423 serial I/O channel


**796-Bus Compatibility**


    D16 M20 I20 VOL.
    6-slot cardcage provided
    basic SUN workstation uses three slots


**Electrical Characteristics**


    110 Volts, 300 Watts
    5 Volt  20 Amp power supply provided


**Physical characteristics**
    Width: 20.5 inch
    Height: 20.5 inch
    Depth: 19 inch

**Environmental Characteristics**

    Operating Temparature: 10-45 C
