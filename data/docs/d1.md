# Sun-2 Multiuser Workstation


Data Sheet

Draft Version 0.4

Company Confidential

Sun Microsystems Inc.

June 7, 1983


>
The Sun-2 Multiuser Workstation is a high-performance implementation of the
Sun-2 architecture for a timeshared system supporting up to eight terminals.
All the electronics of the system are contained on a single board:
processor with virtual memory management, 1 Mbyte of memory,
Ethernet interface, SCSI disk interface, serial I/O, and various system utilities.

The processor is based on a 10 MHz 68010 extended with multiprocess
virtual memory management supporting multiple processes with up to 16 MBytes.
The board contains one megabyte of memory with zero wait state access time.
Memory is equipped with parity error detection.
Both the Ethernet and the SCSI interface transfer data via
direct-virtual-memory-access (DVMA) directly into main memory
without processor intervention.
The system includes 8 serial lines for terminals, plus two serial lines
for I/O devices that feature full modem control with synchronous clock capabilities.

# Introduction


The Sun-2 Multiuser Workstation is a high-performance implementation
of the Sun-2 architecture, providing a powerful network-based
timesharing system for up to eight terminals packaged
on a single, triple height Euro-card.
The board includes the CPU, virtual memory management,
1 megabyte of main memory with parity error detection,
integral Ethernet, SCSI, and RS-423 interfaces,
together with various other facilities,
such as timers and diagnostic hardware.

The processor is based on the Motorola 68010 32-bit VLSI CPU,
extended with the Sun-2 virtual memory management unit (MMU).
The MMU was specifically optimized to support the demand paging requirements
of the the 4.2 BSD version of the Unix (TM) operating system.
It provides multiple, simultaneous process contexts, each of which
can access their own 16 megabyte virtual memory space. In addition,
the MMU provides separate address spaces for the system and for the user.

The system includes 1 Mbyte of main memory with parity error detection.
The system has been carefully designed so that the CPU can access main memory
without introducing any wait states, delivering the highest possible performance.
On-board memory can be configured for 4 Mbytes when 256K dynamic RAMs become
available.

Input/Output of the system include Ethernet, SCSI, and serial line interfaces.

The Ethernet interface uses a VLSI Ethernet controller that features
high-performance frame handling and extensive diagnostic capabilities.
Ethernet packets are directly transferred in and out of main memory
through the use of a direct virtual memory access (DVMA) mechanism.

The SCSI interface implements a high-performance, single-host interface
that can control up to seven target devices.
Like the Ethernet interface, the SCSI interface uses DVMA
to directly transfers data in and out of main memory.

The system includes eight serial I/O ports without modem control
and two serial I/O ports with full modem control.
All ports are implemented with a highly programmable serial communication controller,
featuring software programmable baud rates from 75 Baud to 19.2 KBaud,
and supporting asynchronous, synchronous, or bit-stuffing protocols.
The two serial lines with the modem control are intended for I/O devices
such as printers and modems.

Other features of the board include programmable timers,
a real-time clock with battery backup, and an identification PROM containing
software readable serial number, revision level, Ethernet address
and other configuration parameters. An optional DES encryption processor
allows secure communication in a network environment.

A number of facilities for software and hardware diagnostics are also
provided. Among them are a bus-error register, a diagnostic display for
displaying error messages, and a watchdog timer for automatic restart
should the CPU ever halt.

# Specification Summary


## CPU





- 10-MHz M68010 CPU




## Memory





- 1 MByte of onboard main memory (64k RAM)

- 4 MByte of onboard main memory (256k RAM)

- high-speed, no-wait state operation

- transparent hardware memory refresh

- byte parity error detection




## Memory Management Unit





- two-level, multiprocess virtual memory management

- full support for demand paging

- 16 Mbytes virtual address space per process

- separate address spaces for supervisor and user

- valid, accessed, and modified tags to assist paging algorithms

- separate read, write, and execute tags for user and supervisor accesses




## Ethernet Interface





- VLSI Ethernet controller (Intel 82586)

- digital phase decoder

- packets transferred directly in and out of main memory

- extensive diagnostic capabilities




## SCSI Interface





- high-speed data transfers directly in and out of main memory

- single initiator, multiple target interface

- up to 7 controllers with up to 8 devices per controller

- optional parity checking on SCSI transfers




## Serial I/O Ports





- eight programmable serial i/o ports without modem control

- two programmable serial i/o ports with full modem control

- based on synchronous communication controller (Zilog 8530)

- software programmable baud rates (75 Baud to 19.2 Kbaud)

- asynchronous, synchronous, and bit-stuffing protocols




## Other Features





- 16K or 32K bytes EPROM (2764, 27128)

- five programmable 16-bit timers (AMD 9513)

- software interrupt capability

- optional DES encryption processor (AMD 9518)

- software readable identification PROM
- (containing serial number and other information)




## Diagnostic Features





- diagnostic LED display

- bus error register

- watchdog reset timer

- bus timeout timer




## Electrical Characteristics





- +5V +-5% at 12 Amps, max.

- +12V +-10% at 0.5 Amps, max. (for Ethernet)




## Physical Characteristics





- Width: 14.44 in. (366.7 mm)

- Height: 15.75 in. (400.0 mm)

- Depth:  0.80 in. (20.0 cm)

- Weight: 64 oz.   (1788 g)




## Environmental Characteristics





- Operating Temperature: 0-50 C
