<center>**The SUN Workstation - Product Overview**</center>


The SUN Workstation (TM) combines high-performance graphics,
processing, and networking capabilities in a desk-top workstation.
The following describes the features of this system in more detail.

The display has a 17" wide-format screen with 1024 by 800 points resolution.
It can display two pages of characters and graphics, including
proportionally spaced characters, foreign alphabets, and mathematical symbols,
as well as lines, curves, and shaded images.
High-speed "RasterOp" hardware allows to write a full screen of
variable-width characters in less than 100 milliseconds.

In addition to the black and white display, a color display option is available.
The color display offers a 640 by 480 display with 256 simultaneous
colors from a palette of over 16 Million.
The display is addressed in (x,y) coordinates and can be updated
in 250 milliseconds. Video output is RS-170 compatible.

The processor is based on the Motorola 68000/68010 CPU, extended with
a powerful virtual memory management unit that allows demand paging
and rapid task switching between multiple processes.
The 68010 version of the system, scheduled for 1Q83, supports
processes with up to 8 MBytes of virtual memory each.
Main memory size starts with 256 kilobytes and is expandable to 1.75 MByte
with the SUN 768 Kbyte memory expansion board.
A typical system is expected to have 1 MByte.
All memory is equipped with parity-error detection.

The SUN 68000/68010 processor has been designed to operate
at 10 MHz at full speed without wait states.
The performance of this system has been benchmarked to approach the
performance of the DEC VAX11/780 for non-floating point work.

The SUN workstation uses Ethernet for its local network.
A 10 Mbit/sec Ethernet interface is scheduled for 4Q82.
An interface for the experimental 3 MBit/sec Ethernet-1 is available now.

The SUN Workstation uses the Intel Multibus (TM Intel Corp) as a system bus.
This provides hardware expandibility with a wide number of board-level products.
Multibus options include disk and tape controllers.

The disk controller option interfaces the SUN Workstation
to high-performance SMD Winchester disk drives.
Two 8" Winchester drives are currently offered:
an 65 MByte drive with 20 msec access time and a
12 MByte (6 fixed, 6 removable) drive with 50 msec access time.

The tape controller option interfaces the SUN Workstation to industry standard
1/2 inch tape drives.

The workstation electronics and the display are packaged
in a desktop enclosure measuring HxWxD 19x17x17 inches.
Power requirement is 110 Volts, 3 Amp.
