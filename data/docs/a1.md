# Sun-2 Single Board Workstation


Data Sheet

Draft Version 1.2

Company Confidential

Sun Microsystems Inc.

May 19, 1983


>
The Sun-2 Single Board Workstation provides on a single, triple height
Eurocard all components of a high-performance engineering/scientific workstation:
processor, memory, virtual memory management, display subsystem, networking,
disk interface, serial I/O, and various system utilities.

The processor is based on a 10 MHz 68010 extended with multiprocess
virtual memory management supporting multiple processes with up to 16 MBytes.
A floating point processor, a data ciphering processor, and a
raster operation processor can optionally be added.
The board contains one megabyte of memory with zero wait state access time.
Memory is equipped with parity error detection.
The display subsystem features 1152 by 900 pixel resolution and is able
to refresh non-interlaced monitors flickerfree at 70 Hz.

Both the Ethernet and the SCSI interface transfer data via
direct-virtual-memory-access (DVMA) directly into main memory
without processor intervention.
The Sun-2 Single Board includes 6 serial lines, two of which feature
full modem control with synchronous clock capabilities, two without
modem control, and two for keyboard and mouse input devices.

# Features


## Processor


- 32-bit VLSI CPU

- 1 or 4 MBytes of zero-wait state main memory

- main memory expandable to 2 or 8 MBytes

- multiprocess, demand paging virtual memory management

- 16 Mbytes virtual address space per process

- optional IEEE standard floating point processor

- optional DES encryption processor

- optional Raster operation processor


## Display


- dedicated dual-ported frame buffer

- 1152 by 900 pixel display resolution

- 70 Hz non-interlaced video refresh


## I/O


- integral Ethernet interface

- integral SCSI interface

- both Ethernet and SASI transfer directly into memory

- six programmable serial I/O ports

- software programmable sound generator


## Other Features


- system bus electrically compatible with VME Bus

- DVMA (direct virtual memory access) from VME Bus

- five programmable 16-bit timers

- up to 64K bytes EPROM

- numerous self-diagnostic capabilities

- triple-height Eurocard form factor

- single +5V power supply (+12V for Ethernet)

# Introduction


The Sun-2 Single Board Workstation is a high-performance implementation
of the Sun-2 architecture, providing all the features of a
high-performance engineering/scientific workstation
on a single, triple height Euro-card.
The board includes the CPU, virtual memory management,
optional processor enhancements,
1 megabyte of main memory with parity error detection,
a high-resolution display subsystem,
integral Ethernet, SCSI, and RS-423 interfaces,
together with various other facilities,
such as timers and diagnostic hardware.

The processor is based on the Motorola 68010 32-bit VLSI CPU,
extended with the Sun-2 virtual memory management unit (MMU).
The facilities of the CPU can be extended by adding various options,
such as a high-speed DES encryption processor, a VLSI floating point
processor implementing IEEE standard single and double precision arithmetic,
and a Raster operation processor for high-speed bitmap transformations.

The MMU was specifically optimized to support the demand paging requirements
of the the 4.2 BSD version of the Unix (TM) operating system.
It provides multiple, simultaneous process contexts, each of which
can access their own 16 megabyte virtual memory space. In addition,
the MMU provides separate address spaces for the system and for the user.

The system includes 1 Mbyte of main memory with parity error detection.
This memory can be expanded to 2 MBytes with a memory expansion board.
The system has been carefully designed so that the CPU can access main memory
without introducing any wait states, delivering the highest possible performance.
On-board memory can be configured for 4 Mbytes when 256K dynamic RAMs become
available, expandable to 8 Mbytes with the memory expansion board.

Integral to the Sun-2 Single Board Workstation is a high-resolution
bitmap display subsystem featuring a 1152 by 900 pixel display area
and non-interlaced, 70 Hz refresh. The display is refreshed out of
a separate, dual-ported frame buffer memory for maximum performance.

Input/Output of the system include Ethernet, SCSI, and serial line interfaces.

The Ethernet interface uses a VLSI Ethernet controller that features
high-performance frame handling and extensive diagnostic capabilities.
Ethernet packets are directly transferred in and out of main memory
through the use of a direct virtual memory access (DVMA) mechanism.

The SCSI interface implements a high-performance, single-host interface
that can control up to seven target devices.
Like the Ethernet interface, the SCSI interface uses DVMA
to directly transfers data in and out of main memory.

The system includes six serial I/O ports which are implemented
with highly programmable serial communication controllers.
All ports feature software programmable baud rates from 75 Baud to 19.2 KBaud,
and support asynchronous, synchronous, or bit-stuffing protocols.
The two primary serial ports offer full modem control with RS-423 levels.
The two secondary serial ports offer receive and transmit data only.
The last two serial ports offer receive and transmit data at TTL-levels only
and are intended for keyboard and mouse interfaces.

Other features of the board include programmable timers,
a real-time clock with battery backup, and an identification PROM containing
software readable serial number, revision level, Ethernet address
and other configuration parameters.
A number of facilities for software and hardware diagnostics are also
provided. Among them are a bus-error register, a diagnostic display for
displaying error messages, and a watchdog timer for automatic restart
should the CPU ever halt.

# Specification Summary


## CPU





- 10-MHz M68010 CPU




## Memory





- 1 MByte of onboard main memory (64k RAM)

- 4 MByte of onboard main memory (256k RAM)

- memory expandable to 2 MBytes/8 Mbytes with expansion board

- high-speed, no-wait state operation

- transparent hardware memory refresh

- byte parity error detection




## Memory Management Unit





- two-level, multiprocess virtual memory management

- full support for demand paging

- 16 Mbytes virtual address space per process

- separate address spaces for supervisor and user

- valid, accessed, and modified tags to assist paging algorithms

- separate read, write, and execute tags for user and supervisor accesses




## CPU OPtions





- Raster operation processor (proprietary)

- IEEE standard floating point processor (Intel 80287)

- DES encryption processor (AMD 9518)




## Display Subsystem





- dedicated dual-ported frame buffer memory

- 1152 by 900 display format

- 100 MHz video clock

- 70 Hz non-interlaced video refresh




## Ethernet Interface





- VLSI Ethernet controller (Intel 82586)

- digital phase decoder

- packets transferred directly in and out of main memory

- extensive diagnostic capabilities




## SCSI Interface





- high-speed data transfers directly in and out of main memory

- single initiator, multiple target interface

- up to 7 controllers with up to 8 devices per controller

- optional parity checking on SCSI transfers




## Serial I/O Ports





- six programmable serial i/o ports

- based on synchronous communication controller (Zilog 8530)

- software programmable baud rates (75 Baud to 19.2 Kbaud)

- asynchronous, synchronous, and bit-stuffing protocols

- two primary ports with full modem control, RS-423 levels

- two secondary ports with transmit/receive data only, RS-423 levels

- two tertiary ports with transmit/receive data only, TTL levels




## Other Features





- System bus interface compatible with VME Bus electrical specifications

- DVMA (direct virtual memory access) from VME Bus

- up to 64K bytes EPROM (2764, 27128, or 27256)

- five programmable 16-bit timers (AMD 9513)

- programmable sound generator (TI 76489)

- software interrupt capability

- software readable identification PROM
- (containing serial number and other information)




## Diagnostic Features





- diagnostic LED display

- bus error register

- watchdog reset timer

- bus timeout timer




## Electrical Characteristics





- +5V +-5% at 17 Amps, max.

- +12V +-10% at 0.5 Amps, max.




## Physical Characteristics





- Width: 14.44 in. (366.7 mm)

- Height: 15.75 in. (400.0 mm)

- Depth:  0.80 in. (20.0 cm)

- Weight: 64 oz.   (1788 g)




## Environmental Characteristics





- Operating Temperature: 0-50 C
