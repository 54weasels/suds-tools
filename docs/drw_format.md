# DRW File Format Specification

**Source**: Rich Alderson (alderson+news@panix.com), alt.sys.pdp10 article 1579, 2000-10-19  
**Preserved in**: `/sun/saildart/SUDS/tools/suds.txt`  
**Authoritative source**: PDP-10 assembly in `IN.FAI[NEW,DRW]` / `OUT.FAI[NEW,DRW]`  
**SUDS Version**: 21 decimal (0o25 octal) — written by IOVER in `LOWCOR.FAN[N,DRW]:189`

> **Note**: The suds.txt spec describes version 24 but the actual SMI files are all
> version 21 (0o25). The PDP-10 source code is the authoritative reference for version
> gating and record formats. Assembly comparison constants are **OCTAL**.

---

## Notation Convention

```
--------
!   A
!   B
!   C
--------
D
```

Means: the sequence of words A, B, C is **repeated** until the value of A equals D.

All values are **36-bit PDP-10 words** unless otherwise noted.  
Each word is stored as two 18-bit halves: `LEFT_HALF,,RIGHT_HALF`  
Sentinel value: `400000` (octal) = `0x20000` = `131072` decimal

**ASCIZ strings (RSTRZ)**: Read full 36-bit words; terminate when `word & 0o377 == 0`  
(low 8 bits zero). NOT byte-level — characters at positions 1–4 can be NUL without
terminating the string. `soap.c` gets this wrong with byte-level termination.

## File Structure

### 1. Header

| Field | Type | Description |
|-------|------|-------------|
| VERSION # | word | File format version. SMI files: 21 (0o25). |
| Nomenclature type | ASCIZ | Drawing nomenclature type ("DECPC" for all SMI files) |
| Board type | ASCIZ | Always set to 0 now, ignored on input |

### 2. Type Names (Library Bodies Used)

```
--------
!   ASCIZ /Type names of library bodies actually used in this drawing/
--------
0
```

Repeated until a zero word is encountered.

### 3. Library Filespecs

```
--------
!   ASCIZ /Library filespec/
!   Library BITS
--------
0
```

### 4. Body Definitions

```
--------
!   ASCIZ /Name of Body Definition/
!   BITS,,UNUSED
!   X,Y INITIAL BODY LOC OFFSET (two 18-bit values)
!   X,Y INITIAL BODY LOC CHAR OFFSET (400000 IF USING DEFAULT)
!   --- Pins ---
!   --------
!   !   LOC OF PIN (X,Y)
!   !   BITS,,PINID (PINID IS GENERATED BY PROGRAM)
!   !   PIN POS,,PIN NAME (DEFAULT)
!   --------
!   400000
!   --- Lines (Symbol Graphics) ---
!   --------
!   !   POINTS DESCRIBING LINES IN TYPE
!   !   (LOW ORDER BIT = 1 IF INVISIBLE LINE TO THIS POINT)
!   --------
!   400000
!   --- Properties ---
!   --------
!   !   ASCIZ /VALUE TEXT/
!   !   ASCIZ /PROPERTY NAME TEXT/ (0 IF TEXT ONLY)
!   !   TEXT SIZE (0 IF NOT NORMALLY DISPLAYED)
!   !   TEXT LOCATION
!   !   CONSTANT OFFSET
!   --------
!   0
--------
0
```

**Important**: Line segment data uses the **low-order bit** as a pen flag:
- Bit 0 = 0: **Draw** line to this point (visible)
- Bit 0 = 1: **Move** to this point without drawing (invisible)

**Version-gated fields** (from IN.FAI, all constants OCTAL):

| Field | Condition | V21 (0o25) | IN.FAI line |
|-------|-----------|------------|-------------|
| DIP type string (name2) | 0o10 ≤ ver < 0o23 | NOT read | 922-926 |
| BITS word | ver ≥ 0o13 | Read | 933-937 |
| DEFOFF word | ver ≥ 0o12 | Read | 938-939 |
| DEFOF1 word | ver > 0o23 (CAILE) | Read | 942-944 |
| Pin format v2 (3 words) | ver ≥ 0o17 | 3 words/pin | 960 |
| **BTEXT** properties | ver < 0o23 | NOT used | 1051 |
| **PROPIN** properties | ver ≥ 0o23 | **Used** | 1121-1144 |

**PROPIN format** (version ≥ 0o23 = 19 decimal, including V21):
Each entry: `RSTRZ(value) + RSTRZ(name) + WORDIN(text_size) + WORDIN(text_loc) + WORDIN(const_offset)`.
Terminated by RSTRZ failure (zero word).

**BTEXT format** (version < 0o23, older files only):
Each entry: `WORDIN(loc) + WORDIN(size_info) + WORDIN(const_offset) + RSTRZ(text)`.
Terminated by LOC == 0o400000. If RSTRZ fails, entry is discarded.

### 5. Macros

```
--------
!   ASCIZ /MACRO NAME/
!   BYTE(9) MACRO BODY ENDING WITH 0 BYTE
--------
0
```

### 6. Body Placements (Component Instances)

```
--------
!   LOC OF BODY (X,Y)
!   ORIENTATION + 400000 (IF LOCATION FOLLOWS)
!       CARD LOC (OPT),,BODY LOC
!       X,Y CONSTANT OFFSET OF LOCATION
!       X,Y CHAR OFFSET OF LOCATION
!       BODY BITS,, BODY ID (GENERATED)
!       ASCIZ /NAME OF BODY DEFINITION/
!       --- Local Properties ---
!       --------
!       !   ASCIZ /VALUE TEXT/
!       !   ASCIZ /PROPERTY NAME TEXT/ (0 FOR TEXT ONLY)
!       !   TEXT SIZE
!       !   TEXT LOCATION
!       !   CONSTANT OFFSET
!       --------
!       0
--------
400000
```

### 7. Points (Wiring/Connectivity)

```
--------
!   LOC OF POINT (X,Y)
!   POINT ID (GENERATED)
!   ID OF DOWN (0 IF NONE)
!   ID OF UP (0 IF NONE)
!   ID OF LEFT (0 IF NONE)
!   ID OF RIGHT (0 IF NONE)
!   BITS,,PIN NAME
!   SIZE OF TEXT (IF NOT 0, THE NEXT 2 FOLLOW:)
!       X,Y CONSTANT OFFSET FROM POINT LOC
!       ASCIZ /TEXT/
!       CARD LOC (OPT),,I/O PIN LOC ----> IF CPIN ON IN BITS
!       X,Y CONSTANT OFFSET -----------> IF CPIN ON IN BITS
--------
400000
```

**POINT ID**: Either a generated sequential ID, or `<PIN_ID,,BODY_ID>` for pins.

### 8. Set Centers

```
--------
!   LOC OF SET CENTER (X,Y)
!   --------
!   !   BODY ID
!   --------
!   0
!   --------
!   !   POINT ID
!   --------
!   0
--------
400000
```

### 9. Trailer (Title Block)

| Order | Field |
|-------|-------|
| 1 | ASCIZ /DRAWN BY/ |
| 2 | ASCIZ /TITLE LINE 1/ |
| 3 | ASCIZ /TITLE LINE 2/ |
| 4 | CARD LOC FOR WHOLE DWG |
| 5 | ASCIZ /REVISION STRING/ |
| 6 | ASCIZ /MODULE STRING/ |
| 7 | ASCIZ /VARIABLE STRING/ |
| 8 | ASCIZ /PREFIX STRING/ |
| 9 | ASCIZ /PROJECT STRING/ |
| 10 | ASCIZ /PAGE STRING/ |
| 11 | ASCIZ /OF STRING/ |
| 12 | ASCIZ /DRAWING CODE/ |
| 13 | ASCIZ /SITE LINE 1 STRING/ |
| 14 | ASCIZ /SITE LINE 2 STRING/ |
| 15 | ASCIZ /NEXT HIGHER ASSEMBLY NUMBER STRING/ |
| 16 | ASCIZ /DRAWN BY FILESPEC/ (or literal if starts with ") |
| 17 | ASCIZ /CHECKED BY FILESPEC/ (or literal if starts with ") |
| 18 | ASCIZ /ENGINEERED BY FILESPEC/ (or literal if starts with ") |

### 10. Extra Parts Declaration

```
--------
!   ASCIZ /DESCRIPTION/
!   ASCIZ /PART NUMBER/
!   --------
!   !   # OF PARTS
!   !   LOCATION (IN BODY LOC FORMAT, 0 IS OK)
!   --------
!   0
--------
0
```

### 11. Signal Names

```
--------
!   ASCIZ /SIGNAL NAME/
!   ASCIZ /SIGNAL PROPERTY NAME/
!   ASCIZ /SIGNAL PROPERTY VALUE/
--------
0
```

### 12. DIP Definition Filespecs

```
--------
!   ASCIZ /DIP DEFINITION FILESPEC/
--------
0
```

### 13. Wire Rule Check Filespecs

```
--------
!   ASCIZ /WIRE RULE CHECK FILESPEC/
--------
0
```

## 36-Bit Word Encoding (ITS Evacuated Format)

See `unpack.c` for the definitive implementation.

Bytes 0x00-0xEF: decoded via lookup tables → 7-bit chars → packed 5-per-word  
Bytes 0xF0-0xFF: literal 5-byte encoding of a complete 36-bit word:

```
byte: 000011111111222222 223333333344444444
 bit: 321076543210765432 107654321076543210
```

Where byte 0 contributes bits 35-32, bytes 1-4 provide the remaining 32 bits.

## ASCIZ String Encoding

7-bit ASCII characters packed 5 per 36-bit word (5 × 7 = 35 bits, LSB = 0):

```
Word: [c1:7][c2:7][c3:7][c4:7][c5:7][0:1]
Bits: 35    28    21    14    7     0
```

Strings terminated by a NUL (0x00) character. After the NUL, remaining
character positions in the word are padded.
